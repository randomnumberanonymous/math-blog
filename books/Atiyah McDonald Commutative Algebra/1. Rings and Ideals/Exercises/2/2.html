Question 2

Let \(A\) be a ring and let \(A[x]\) be the ring of polynomials in an indeterminate \(x\), with coefficients in \(A\). Let \(f=a_0+a_1x+\cdots+a_nx^n\in A[x]\).

(i)

Prove that \(f\) is a unit in \(A[x]\) \(\Leftrightarrow\) \(a_0\) is an unit in \(A\) and \(a_1,\ldots,a_n\) are nilpotent.

Hint: If \(b_0+\cdots b_mx^m\) is the inverse of \(f\), prove by induction on \(r\), that \(a_n^{r+1}b_{m-r}=0\). Hence show that \(a_n\) is nilpotent and then use Ex. \(1\).

Solution

Suppose \(g=b_0+\cdots +b_mx^m\). Let \(h=fg\). If \(h = \sum_i h_ix^i\). Then \(h_i=0\) for \(i>n+m\), and \[h_i = \sum_{k=0}^ia_{i-k}\,b_k,\quad 0\leq i\leq n+m\]

Interlude: A couple of points about polynomials

One of the two fundamental properties of polynomials is that every polynomial has a unique decomposition as a sum of monomials. Monomials are special polynomials that have a non zero component in only one degree. The \(0\) polynomial, is the polynomial whose coefficient in every degree is \(0\). In particular \(0=0 + 0\cdot x+0\cdot x^2+\cdots 0\cdot x^n + \cdots\). The uniquness of the decomposition of a polynomial in terms of monomials implies that this is the unique decomposition for the \(0\) polynomial. This means that if a polynomial is the \(0\) polynomial, then its component in every degree is \(0\). If \(a(x)\) and \(b(x)\) are two polynomials such that \(a(x)=b(x)\) or equivalently \(a(x)-b(x)=0\), then \(a(x)-b(x) = \sum_i(a_i-b_i)x^i = 0\). So \(a_i-b_i=0\) for all \(i\) or \(a_i=b_i\) for all \(i\). So two polynomials are equal only if their component in each degree are equal. This stems from the unique decomposition of polynomial as a sum of monomials.

By the way for a polynomial \(a(x)=\sum_ia_ix^i\). We call \(a_kx^k\), the component of \(a(x)\) in degree \(k\), while we call \(a_k\) the coefficient of \(a(x)\) in degree \(k\).

The second fundamental property of the polynomials is how they multiply, \(ax^n \cdot bx^m = abx^{m+n}\). Using this and the distributive and commutative properties of the operations in commutative rings we get the multiplication for general polynomials.

Suppose \(g\) is the (multiplicative)inverse of \(f\). \[(b_0+\cdots +b_mx^m)(a_0+a_1x+\cdots+a_nx^n) = 1.\]

So \(h=fg = 1\). Then \(h_0=1\) and \(h_i=0\) for all \(i>0\).

\(h_0 = \sum_{k=0}^0a_{0-k}b_k = a_0b_0\), as the sum has only one summand. So \(a_0b_0=1\). This implies that \(f_0 = a_0\) is a unit.

Now we want to prove by induction that \(a_n^{r+1}b_{m-r}=0\) for \(0\leq r\leq m\). This will imply that \(a_n^{m+1}b_0=0\). But \(b_0\) is a unit as we just proved. This will imply that \(a_n^{m+1}=0\). This will imply that \(a_n\) is nilpotent. Hence \(a_nx^n\) is nilpotent. But by Ex \(1\), \(f^{(n-1)}(x) = f(x)-a_nx^n\) is a unit, where \(f^{(n-1)}(x) = a_0+\cdots+a_{n-1}x^{n-1}\) is the polynomial got from \(f(x)\) by keeping terms upto degree \(n-1\). If \(n-1>0\), then we can repeat this process to show that \(a_{n-1}\) is nilpotent. Iterating this \(n-2\) more times we can show that \(a_1,a_2,\ldots,a_{n-2}\) are nilpotent. Hence we have proved that if \(f(x)\) is an unit then \(a_0\) is an unit and \(a_i\) is nilpotent for \(i>0\).

If \(n+m=0\), then \(f\) is a degree \(0\) polynomial and a unit. So its coefficient in all positive degree is \(0\), so it satisfies the assertion. If \(n+m>0\), then \(h_{n+m} = \sum_{k=0}^{n+m}a_{n+m-k}b_k = a_nb_m\), as this sum also has only one summand. So \(a_nb_m=0\). So \(a_n^{0+1}b_{m-0} =0\). Thus the statement “\(a_n^{r+1}b_{m-r}=0\)” is true for \(r=0\).

Let us make the induction hypothesis that for \(1 < r < k\leq m\), \(a_n^{r+1}b_{m-r}=0\).

\(h_{n+m-k} = a_{n+m-k}b_0+a_{n+m-k-1}b_1+\cdots+a_0b_{n+m-k} = 0\). As \(k\leq m\), we have \(n+m-k\geq n>0\). So \(h_{n+m-k}=0\). Also note \(a_{n+(m-k)}=a_{n+(m-k)-1}=\cdots=a_{n+1}=0\). So we have \(h_{n+m-k} = a_nb_{m-k}+a_{n-1}b_{(m-k)+1}+\cdots+a_0b_{n+m-k} = 0\). Let us multiply by \(a_n^{k}\), we get \(a_n^k(a_nb_{m-k}+a_{n-1}b_{(m-k)+1}+\cdots+a_0b_{n+m-k}) = 0 = a_n^k\cdot 0 = 0\). So \(a_n^{k+1}b_{m-k}+a_{n-1}a_n^kb_{m-(k-1)}+\cdots+a_0a_n^{n-1}a_n^{k-n+1}b_{m-(k-n)}=0\). But by induction hypothesis \(a_n^kb_{m-(k-1)},a_n^{k-1}b_{m-(k-2)},\ldots, a_nb_m\) are \(0\). Also if \(k-n<0\), then \(b_{m+1},\ldots,b_{m-(k-n)}\) are also \(0\). So \(a_{n-1}a_n^kb_{m-(k-1)}+\cdots+a_0a_n^{n-1}a_n^{k-n+1}b_{m-(k-n)}=0\). Hence \(a_n^{k+1}b_{m-k}=0\). So the induction step holds good. So \(a_n^{r+1}b_{m-r}=0\) holds for \(1\leq r\leq m\).

For the reverse implication note that if \(a_i\) is nilpotent for \(i>0\), then \(a_ix^i\) is also nilpotent. The sum of two nilpotent elements \(a,b\) is also nilpotent. Suppose \(a^m=b^n=0\), then \((a+b)^{m+n-1} = \sum \binom{m+n-1}{p}a^pb^{m+n-1-p}\). But for \(0\leq p\leq m+n-1\) either \(p\geq m\) (and)or \(m+n-1-p\geq n\). So the product in each of the summands in this sum is \(0\). So \((a+b)^{m+n-1}=0\). So \(a+b\) is also nilpotent. From this we can conclude that a finite sum of nilpotent elements is nilpotent. Hence the sum \(\sum_{i>0}a_ix^i\) is nilpotent. Since \(a_0\) is an unit. Using exercise \(1\) the sum \(\sum_{i\geq 0}a_ix^i\) is an unit. Note that there are only finitely many terms in these sums.

Note: If a polynomial \(f(x)\) is a unit, then \(f_0\) is a unit. This also holds good for polynomials in more than \(1\) variable and also in power series rings in one or more than one variable. The proof of this fact in these rings is similar to the proof for polynomials in \(1\) variable case.

(ii)

\(f\) is nilpotent \(\Leftrightarrow\) \(a_0,a_1,\ldots,a_n\) are nilpotent.

Solution

As in the proof of the reverse implication in part (i), if \(a_i,i\geq 0\) are nilpotent then \(a_ix^i\) are nilpotent. Hence the sum \(\sum_{i\geq 0}a_ix^i\) is nilpotent. So \(f(x)\) is nilpotent.

Note that we cannot have that \(a, a+b\) are nilpotent but \(b\) is not nilpotent for elements \(a,b\). It is so because \(b = (a+b)-(a)\) and the sum and difference of two nilpotents is nilpotent. But the sum of two non nilpotents can be nilpotent. For example \(1+(-1)=0\).

The constant term of \(f^r\) is \(a_0^r\). So if \(f^R=0\). We must also have that the constant term of \(f^R=0\). So we have that \(a_0^R=0\). Hence \(a_0\) is nilpotent. A similar argument will imply the leading coefficient \(a_n\) must also be nilpotent. Specifically if \(f^R=0\). Then the coefficient of \(x^{nR}\) in \(f^R\) is \(a_n^R\). Hence \(a_n^R=0\). Hence \(a_n\) is nilpotent. Thus \(a_nx^n\) is nilpotent. So \(f-a_nx^n = a_0+\cdots+a_{n-1}x^{n-1}\) is also nilpotent. Iterating this \(n-1\) times we will get that \(a_0,a_1,\ldots,a_{n-1}\) are nilpotent.

(iii)

\(f\) is a zero-divisor \(\Leftrightarrow\) there exists \(a\neq 0\) in \(A\) such that \(af=0\).[Choose a \(^{\text{nonzero}}\) polynomial \(g=b_0+b_1x+\cdots+b_mx^m\) of least degree \(m\) such that \(fg=0\). Then \(a_nb_m=0\), hence \(a_ng=0\) (because \(a_ng\) annihilates \(f\) and has degree \(< m\)). Now show by induction that \(a_{n-r}g=0\,(0\leq r\leq n)\).]

Solution

Given an element \(m\) of a module \(M\) over a ring \(R\), consider the map \[R\to M,\quad r\mapsto rm.\] The image of this map is commonly denoted as \(\langle m\rangle\) or \(Rm\) is called the cyclic submodule generated by \(m\) in \(M\). The kernel of this map is the set of elements \(\{r\in R: rm=0\}\). This kernel is called the Annhilator of \(m\), and is denoted \(\text{Ann}_R\,m\). If one things of multiplication by elements of a ring as an action of the ring on the module(\(\phi_r(m)=rm\)), then elements in \(\ann{m}\) kill or annhilate \(m\) under this action.

Clearly \(f\) is a zero-divisor if and only it has non zero Annihilator.

This exercise asks us to prove that if the Annhilator of a polynomial is nonzero then the Annhilator contains a degree \(0\) element.

When we are considering the Annhilator of an element \(r\) of a ring, we are considering \(R\) as a module over itself.

Suppose \(f\) is a zero divisor. Equivalently \(\text{Ann}_R\,f \neq 0\). If a subset of the polynomial ring contains nonzero elements, then the set of degrees of the nonzero elements in that subset has a least degree. As the Annhilator \(\ann{f}\) is nonzero then there is a least degree among the degrees of the nonzero polynomials in it. Let \(g = \sum_{r=0}^mb_rx^r\) be an element of \(\ann{r}\) of least degree.

If \(\deg g =0\), then then \(f\) satisfies the condition, that we needed to prove.

Suppose \(\deg g > 0\). We have \(gf=0\). So \((gf)_{n+m}=b_ma_n=0\). Note \(ga_n\in\ann{r}\). Also \(\deg a_ng < m = \deg g\) as the coefficient of \(x^m\) in \(a_ng\) which is \(a_nb_m\) is \(0\). So \(a_ng\) can not be nonzero, as it contradicts that \(m=\deg g\) is the least among the degrees of non zero elements in the annhilator \(\ann{f}\).

So \(a_ng = 0\). This is equivalent to saying \(a_nb_r=0\) for \(r=0,1,\ldots,m\). In other words \(a_n\in\ann{\{b_r:0\leq r\leq m\}}\).

If we prove that \(a_i\in \ann{\{b_r:0\leq r\leq m\}}\) for \(i=0,\ldots,n\). This will imply that \(b_r\in\ann{\{a_i:0\leq i\leq n\}}\) for all \(r\). This will imply that \(b_r\in\ann{f}\). Since \(g\neq 0\), atleast one \(b_r\neq 0\). So there exists a non zero degree 0 element in \(\ann{f}\). This will be the solution to the given question.

We will now prove that \(a_i\in \ann{\{b_r:0\leq r\leq m\}}\) for \(i=0,\ldots,n\). We will use induction to prove this. Note that we have assumed \(m>0\) or that \(\deg g>0\).

We have proved this statement for \(i=n\). This is the initial case. We need to prove this for \(i=0,1,\ldots,n\). The induction hypothesis is: Suppose this statement is true for \(i>k\), where \(k=0,\ldots,n-1\). The induction step is to prove this for \(i=k\), under the induction hypthesis. So we need to prove \(a_k\in\ann{\{b_r:0\leq r\leq m\}}\). This is equivalent to proving \(a_kg=0\).

By the fundamental property of \(g\), \(gf=0\). \(f=f_1+f_2\), where \(f_1 = \sum_{i=0}^k a_ix^i\), and \(f_2 = \sum_{i>k} a_ix^i\). By the induction hypothesis \(a_ig=0\) for \(i>k\). This implies that \(f_2g=0\). So \(f_1g=fg-f_2g=0\). So \(g\) annhilates \(f_1\). The coefficient of \(x^{k+m}\) in \(f_1g\) is \(a_kb_m\) and it should also be \(0\). So \(a_kb_m=0\). This implies that: \(\deg a_kg<m\). Since \(a_kg\in\ann{f}\) this implies that \(a_kg=0\). This proves the induction step.

We have used crucially if \(r\in R\) annhilates the leading coefficient of \(g\), then it must annhilate \(g\).

This concludes the proof.

(iv)

\(f\) is said to be primitive if \((a_0,a_1,\ldots,a_n)=(1)\). Prove that if \(f,g\in A[x]\), then \(fg\) is primitive \(\Leftrightarrow\) \(f\) and \(g\) are primitive.

Solution

The notation \((a_0,a_1,\ldots,a_n)\) denotes the ideal generated by the elements \(a_0,a_1,\ldots,a_n\). If \(a\in (b)\), for \(a,b\) in a ring \(R\), then \(a=br\) for some \(r\in R\). Hence when \(a\in (b)\), we sometimes say \(b\) divides \(a\) or \(b|a\). If \(a\in (b)\) and \(b\in (a)\), then \(a=rb\) and \(b=r'a\) for some \(r,r'\) in the ring. So \(a=rr'a\) and \(b=r'rb\). This implies \((1-rr')a=0\) and \((1-r'r)b=0\). If \(R\) is an integral domain and \(a,b\) are nonzero elements, then we must have \(1-r'r=0\) or \(r'r=1\). Hence when \(R\) is an integral domain and \(a,b\) are two nonzero elements dividing each other then \(a=rb\) and \(b=r'a\), where \(r,r'\) are units. We also have that \((a)=(b)\). Sometimes they are called associates. The terms like divisibility are mostly used in integral domains. In integral domains \((a)=(b)\Leftrightarrow a|b \text{ and } b|a\). In this context if \((a_0,a_1,\ldots,a_n)\) is a principal ideal, say it is \((r)\), then \(r\) is said to be the gcd of \(a_0,a_1,\ldots,a_n\). \((1)=R\), and if for two elements \((a,b)=(1)=R\), we say \(a,b\) are coprime. \((1)\) is called the unit ideal(the ideal generated by any unit).

For this question our base ring is \(A\), rather than our usual \(R\).

A polynomial \(f(x)=\sum_{i=0}^na_ix^i\) is primitive if \((a_0,a_1,\ldots,a_n)=(1)=A\). If \(f(x)\) is not primitive then \((a_0,a_1,\ldots,a_n)\neq A\). But it need not be a principal ideal, that is if \(f\) is not primitive it does not mean that \((a_0,a_1,\ldots,a_n)=(a)\) for some \(a\in A\). This ideal may not be principal in general. Ofcourse if \(A\) is a Principal Ideal Domain then this ideal is principal, and in this case \((a_0,a_1,\ldots,a_n)=(c_f)\), the generator \(c_f\) is called the content of \(f\).

Given a polynomial \(p_0+p_1x+\cdots +p^kx^k\), let \(c(p)\) denote the ideal generated by the coefficients of \(p\). So \(c(p)=\langle p_0,p_1,\ldots,p_k\rangle\). \(c(p)\) is called the content ideal of the polynomial \(p\).

Let \(f=\sum_{i=0}^na_i\,x^i\) and let \(g=\sum_{j=0}^mb_j\,x^j\). So \(c(f)\) and \(c(g)\) are the ideals \((a_0,a_1,\ldots,a_n)\), and \((b_0,b_1,\ldots,b_m)\) respectively. Then the product ideal \(c(f)Cg\) is generated by \(\{a_ib_j:0\leq i\leq n,0\leq j\leq m\}\). Each coefficient of the product polynomial \(fg\) is a sum of some products \(a_ib_j\). Hence each coefficient of \(fg\) is in the ideal \(c(f)c(g)\). So the ideal \(C_{fg}\) is a subideal of \(c(f)c(g)\). That is \(C_{fg}\subset c(f)c(g)\). We have the following sequence of inclusions of ideals \[C_{fg}\subset c(f)c(g)\subset c(f)\cap c(g).\]

If \(C_{fg}=A\). Then \(c(f)\cap c(g)=A\). As \(c(f)\cap c(g) \subset c(f)\) and \(c(f)\cap c(g) \subset c(f)\), we have that \(c(f)=A\) and \(c(g)=A\). So if \(fg\) is primitive then \(f\) is primitive and \(g\) is primitive.

If \(c(f)=A\) and \(c(g)=A\). Suppose \(C_{fg}\neq A\). Then by a fundamental property of commutative rings proved using Zorn’s lemma, there exists a maximal ideal containing \(C_{fg}\). Denote this ideal by \(\mathfrak m\). The quotient ring \(k_\mathfrak m = A/\mathfrak m\) is a field, called the residue field of \(\mathfrak m\). I think the name “residue field” stems from the case when \(A=\mathbb Z\) and \(\mathfrak m=(p)\), where \(p\) is a prime number. Then the “classes” in the quotient ring \(\mathbb Z/(p)\) are represented by the remainders modulo \(p\). These remainders are sometimes called the residues.

Consider the homomorphism \(A \to k_\mathfrak m\). This map extends naturally to the homomorphism \(A[x]\to k_\mathfrak m[x]\), such that \(\sum_{i=0}^n a_ix^i\mapsto \sum_{i=0}^n\overline{a_i}x^i.\) At this stage we have to check that this extension exists explicitly. At a higher level we can say the following: tensor the map \(A\to k_\mathfrak m\) by \(A[x]\) over \(A\). Note that the quotient \(k_\mathfrak m=A/\mathfrak m\) is a \(A\) module. So we have \[(A\to k_\mathfrak m)\otimes_A A[x] = A\otimes_ AA[x]\to k_\mathfrak m\otimes_A A[x] = A[X]\to k_\mathfrak m[x],\quad \sum_{i=0}^n a_ix^i\mapsto \sum_{i=0}^n\overline{a_i}x^i.\]

Under this homomorphism \(fg\) map to \(\overline{fg}\), which is equal to \(\overline{f}\cdot \overline{g}\), because this map is a homomorphism. Since the coefficients if \(fg\) are in \(\mathfrak m\), their image in \(k_\mathfrak m\) is \(0\). So the image of \(fg\) is \(0\) in \(k_\mathfrak m[x]\). As the coefficients of \(f\) generates the unit ideal, all the coefficients of \(f\) are not in \(\mathfrak m\), or else \(\mathfrak m\) would be \(A\). So there exists atleast one coefficient of \(f\), whose image in \(k_\mathfrak m\) is nonzero. Hence the image of \(f\), under this map will be nonzero. Similarly the image of \(g\) under this map would be nonzeo. So \(\overline{f}\) and \(\overline{g}\) are nonzero elements in \(k_\mathfrak m[x]\). But their product is \(\overline{fg}\), which is \(0\) in \(k_\mathfrak m[x]\). But this is not possible as \(k_\mathfrak m[x]\) is an integral domain because the coefficient field \(k_\mathfrak m\) is a field. So if \(c(f)=A\) and \(c(g)=A\), then we also must have \(C_{fg}=A\).

This completes the proof.

The proof of “\(f\) and \(g\) are primitive \(\Rightarrow\) \(fg\)” is primitive used a technique that is not transparent. It is very instructive to understand it and try to show expicitly that if some \(R-\)linear combination of the coefficients of \(f\) equals \(1\)(generates unity) and similarly some \(R-\) linear combination of the coefficients of \(g\) equals \(1\), then there exists an \(R-\) linear combination of the coefficients of \(fg\) that equal \(1\).

Note that the proof implies that if the coefficients of \(fg\) are contained in some maximal ideal of \(R\), then that maximal ideal will contain either all the coefficients of \(f\) (and)or it will contain all the coefficients of \(g\). The proof will also work if instead of a maximal ideal, we had taken a prime ideal containing all the coefficients of \(fg\). So if a prime ideal contains all the coefficients of \(fg\), then it must also contain eith all the coefficients of \(f\) (and)or it must contain all the coefficients of \(g\).
