# add_book  add_chapter  add_element  add_section 
- To add a book: books/> source ../utils/add_book "Hartshorne Algebraic geometry"
- To add a chapter: books/<bookname>/> source ../../utils/add_chapter "Chapter I Varieties"
- To add a section: books/bookname/chaptername/> source ../../../utils/add_section "1. Affine Varieties"
- To add an element: books/bookname/chaptername/sectionname/> source ../../../../utils/add_element "Exercise 1.1"
- An element can be a Note, Remark, Exercise, anything else that is in a section.
